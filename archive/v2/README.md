# DarkMatter 2 archive

These strategy notes, promotional assets, and video-generation scripts describe the retired DarkMatter 2 mesh architecture. They are retained for project history only.

They are not documentation for DarkMatter 3. DarkMatter 3 has no autonomous discovery, bootstrap peer, WebRTC transport, mesh routing, broadcast mode, HTTP daemon, or wallet subsystem. See the repository root `README.md` for the current sealed-mail-over-Git contract.
